# C++ While Loop

```CPP
    // Syntax
    while (condition) {
  // code block to be executed
    }
```

```CPP
    // Test1.cpp
    int countdown = 5;
    while (countdown > 0) {
        cout << countdown << endl;
        countdown --;
    }
    cout << "Happy New Year!";
```

## Do/While Loop

```CPP
    // Syntax
    do {
    // code block to be executed
    }
    while (condition);
```

```CPP
    // Test2.cpp
    int countdown = 5;
    do {
        cout << countdown << endl;
        countdown --;
    }
    while (countdown > 0);
    cout << "Happy Birth Day!";
```
